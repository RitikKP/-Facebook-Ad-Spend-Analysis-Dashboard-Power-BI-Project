# -Facebook-Ad-Spend-Analysis-Dashboard-Power-BI-Project
This project showcases my ability to perform data cleaning, modeling, and insightful dashboarding using Power BI, based on real-world data from the Facebook Ads Library (collected on 6 April 2025).
🔍 Project Overview:
Data Source: Facebook Ads Library

Domain: Digital Marketing / Political & Social Ads

Objective: To analyze and visualize ad spend distribution by location and advertiser page.

📌 Key Features:
Top 6 States by Ad Spend visualized with dynamic donut charts

Page-wise ad performance including total ads and spend

Clean and uniform blue-based theme, matching Facebook’s color branding

Responsive filters & slicers for flexible insights

⚙️ Skills & Tools Used:
Power Query: Data cleaning & transformation

DAX Measures: Aggregation of total spend by page and location

Custom color theme and slicers for enhanced UX

Real-time visuals with filtering and drill-down support

⚠️ Disclaimer: This data snapshot is not complete or continuously updated, and may not fully reflect all Facebook ad activity.
